========================================
智慧煤矿ERP管理系统 - 启动项说明
========================================

本文件夹包含系统启动和编译的快捷脚本。

文件说明：
----------
1. 一键启动后端.bat
   - 功能：启动后端服务
   - 端口：8080
   - 说明：双击运行即可启动后端服务

2. 一键启动前端.bat
   - 功能：启动前端开发服务器
   - 端口：5173
   - 说明：双击运行即可启动前端服务

3. 一键编译.bat
   - 功能：编译项目（Maven打包）
   - 说明：首次运行或代码更新后需要执行此脚本
   - 输出：coal-erp-business/target/coal-erp-business-*.jar

使用顺序：
----------
1. 首次部署：
   a) 运行"一键编译.bat"编译项目
   b) 运行"一键启动后端.bat"启动后端
   c) 运行"一键启动前端.bat"启动前端

2. 日常使用：
   a) 运行"一键启动后端.bat"启动后端
   b) 运行"一键启动前端.bat"启动前端

注意事项：
----------
- 确保已安装JDK、Maven、Node.js等环境
- 确保MySQL数据库已创建并初始化
- 确保端口8080和5173未被占用
- 首次运行前端会自动安装依赖（需要网络连接）

访问地址：
----------
- 前端：http://localhost:5173
- 后端：http://localhost:8080
- 默认管理员：admin / admin123
