================================================================================
智慧煤矿ERP管理系统 - 测试数据导入指南
================================================================================

本指南说明如何导入测试数据到系统中。

================================================================================
一、导入前准备
================================================================================

1. 确保数据库已创建
   - 数据库名：coal_erp
   - 字符集：utf8mb4

2. 确保表结构已创建
   - 必须先执行：一键导入数据库.bat
   - 这会创建所有必要的表结构

3. 确保MySQL服务已启动

================================================================================
二、导入方法（三种方法任选其一）
================================================================================

【方法一：使用批处理脚本（最简单，推荐）】
----------------------------------------

Windows系统：
1. 找到项目根目录下的文件：导入测试数据.bat
2. 双击运行该文件
3. 输入MySQL root用户密码
4. 输入 Y 确认导入
5. 等待导入完成

Linux/Mac系统：
1. 打开终端，进入项目根目录
2. 执行：chmod +x 导入测试数据.sh
3. 执行：./导入测试数据.sh
4. 输入MySQL root用户密码
5. 输入 Y 确认导入
6. 等待导入完成

优点：
- 最简单，一键导入
- 自动检查文件是否存在
- 自动提示错误信息

【方法二：使用MySQL命令行】
--------------------------

1. 打开命令提示符（CMD）或PowerShell
2. 进入项目根目录：
   cd D:\Zh-MK
3. 执行导入命令：
   mysql -u root -p coal_erp < coal-erp-business\src\main\resources\db\complete_test_data.sql
4. 输入MySQL root用户密码
5. 等待导入完成

优点：
- 直接使用MySQL命令
- 适合熟悉命令行的用户

【方法三：在MySQL客户端中使用source命令】
----------------------------------------

1. 打开命令提示符，登录MySQL：
   mysql -u root -p
2. 输入密码后，选择数据库：
   USE coal_erp;
3. 执行source命令（注意路径使用正斜杠）：
   source D:/Zh-MK/coal-erp-business/src/main/resources/db/complete_test_data.sql;
4. 等待导入完成

优点：
- 可以在MySQL客户端中查看执行过程
- 适合需要查看详细执行信息的场景

四、导入步骤详解（方法一）
================================================================================

步骤1：双击运行导入脚本
-----------------------
找到项目根目录下的文件：导入测试数据.bat
双击运行

步骤2：输入数据库密码
--------------------
脚本会提示：请输入MySQL root用户密码:
输入你的MySQL root密码（输入时不会显示，直接输入后按回车）

步骤3：确认导入
--------------
脚本会提示：此操作将清空所有业务数据，请确认！
是否继续? (Y/N):
输入 Y 然后按回车

步骤4：等待导入完成
------------------
脚本会自动执行导入，显示进度信息
导入完成后会显示成功信息

步骤5：验证导入结果
------------------
可以登录系统查看各模块是否有数据
或使用SQL查询验证数据是否导入成功

================================================================================
五、常见问题解决
================================================================================

问题1：提示"未找到mysql命令"
---------------------------
原因：MySQL未安装或未添加到系统PATH
解决：
1. 检查MySQL是否已安装
2. 将MySQL的bin目录添加到系统PATH环境变量
3. 或使用完整路径：C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe

问题2：提示"SQL文件不存在"
-------------------------
原因：脚本未在项目根目录执行，或文件路径不正确
解决：
1. 确保在项目根目录（D:\Zh-MK）执行脚本
2. 检查文件是否存在：coal-erp-business\src\main\resources\db\complete_test_data.sql

问题3：提示"Table 'xxx' doesn't exist"
-------------------------------------
原因：表结构未创建
解决：
1. 先执行：一键导入数据库.bat
2. 这会创建所有必要的表结构
3. 然后再执行测试数据导入

问题4：提示"Unknown column 'xxx' in 'field list'"
-------------------------------------------------
原因：表结构字段不匹配
解决：
1. 确保已执行最新的表结构创建脚本
2. 检查表结构是否与SQL文件中的字段匹配

问题5：提示"Access denied"
-------------------------
原因：数据库用户权限不足
解决：
1. 使用root用户执行导入
2. 或使用具有TRUNCATE和INSERT权限的用户

问题6：导入后数据为空
--------------------
原因：可能导入失败但未显示错误
解决：
1. 检查MySQL错误日志
2. 使用MySQL客户端手动执行SQL文件查看详细错误
3. 确保表结构已正确创建

================================================================================
七、注意事项
================================================================================

⚠️ 重要提示：

1. 导入会清空所有业务数据
   - 测试数据导入脚本会先清空所有业务表
   - 请确保没有重要数据，或先备份

2. 必须先创建表结构
   - 必须先执行：一键导入数据库.bat
   - 这会创建所有必要的表结构
   - 然后再导入测试数据

3. 不要复制粘贴SQL语句
   - SQL文件很长，复制粘贴会被截断
   - 必须使用文件导入方式

4. 确保数据库连接正常
   - MySQL服务必须已启动
   - 数据库必须已创建
   - 用户必须有足够权限

5. 导入后建议重启服务
   - 导入完成后，建议重启后端服务
   - 确保缓存数据已更新
